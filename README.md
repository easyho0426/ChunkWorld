# 청크월드 온라인 (Render 배포용)

기존 청크월드 HTML 게임에 WebSocket 멀티플레이 기능을 추가한 Render 배포용 프로젝트입니다.

## 배포 방법
1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Render 대시보드에서 **New + → Web Service**를 선택하고 GitHub 저장소를 연결합니다.
3. Runtime은 **Node**, Build Command는 `npm install`, Start Command는 `npm start`로 설정합니다.
4. 배포가 완료되면 Render가 제공하는 `https://...onrender.com` 주소로 접속합니다.
5. 친구도 같은 주소에 접속한 뒤 시작 화면에서 **같은 월드 시드**를 입력하고 플레이하면 같은 방에 들어갑니다.

## 현재 멀티플레이 범위
- 같은 방에 접속한 플레이어의 위치/방향 표시
- 블록 설치 및 파괴 이벤트 실시간 전달
- Render가 WebSocket 연결을 처리

## 알아둘 점
- 이 버전은 멀티플레이 프로토타입입니다. 인벤토리, 체력, 몹, 상자/화로, 저장 데이터는 서버에서 공유하지 않습니다.
- 새로 들어온 플레이어에게 기존 플레이어가 변경한 블록 전체를 보내는 월드 저장/동기화는 아직 구현되지 않았습니다. 모두 같은 시드로 시작하고 이후 변경을 함께 확인하는 용도입니다.
- Render 무료 인스턴스는 비활성 상태에서 잠들 수 있어 첫 접속이 느릴 수 있습니다.
- Three.js와 Google Fonts는 CDN을 사용하므로 접속 기기에서 인터넷 연결이 필요합니다.
